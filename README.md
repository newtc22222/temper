# Temper

Seventeen short lessons on Axum for someone who already reads Rust. This course starts after [Patina](https://patina-rust.netlify.app), the language course, and does not replace it. One framework, one in-memory notes program.

Progress stays in the browser. There is no account.

```bash
npm install
npm run dev
```

Netlify builds with `DEPLOY_TARGET=netlify npm run build` (`netlify.toml`). The live page is [temper-axum.netlify.app](https://temper-axum.netlify.app).
